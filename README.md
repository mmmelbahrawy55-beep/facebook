# Freebuff - نظام نشر إعلانات التوظيف

نظام آلي لنشر إعلانات التوظيف على مجموعات فيسبوك في المحافظات المصرية.

## 🚀 الميزات

- ✅ تسجيل الدخول إلى فيسبوك عبر المتصفح
- ✅ اكتشاف تلقائي للمجموعات حسب المحافظة
- ✅ إنشاء إعلانات توظيف بالصور والنصوص
- ✅ النشر الآلي إلى جميع المجموعات في المحافظة المحددة
- ✅ سجل كامل للنشر الناجح والفاشل
- ✅ واجهة عربية سهلة الاستخدام

## 📋 المتطلبات

- Node.js 18+ 
- npm أو yarn
- متصفح Chrome (يُستخدم تلقائياً مع Puppeteer)

## 🛠️ التثبيت

```bash
# 1. تثبيت التبعيات
npm install

# 2. تشغيل التطبيق
npm run dev
```

## 📖 طريقة الاستخدام

### 1. الاتصال بفيسبوك
- اضغط على "اتصال فيسبوك" في شريط الحالة
- ستفتح نافذة متصفح فيسبوك
- سجّل الدخول يدوياً في المتصفح
- عُد إلى التطبيق واضغط "تم تسجيل الدخول"

### 2. اكتشاف المجموعات
- اختر المحافظة من القائمة المنسدلة
- اضغط "اكتشاف مجموعات المحافظة"
- سيبحث النظام عن مجموعات التوظيف في المحافظة
- يتم حفظ المجموعات المكتشفة تلقائياً

### 3. إنشاء إعلان
- املأ عنوان الإعلان
- اكتب وصف الإعلان التفصيلي
- اختر المحافظة المستهدفة
- (اختياري) أضف صورة للإعلان
- اضغط "حفظ الإعلان"

### 4. نشر الإعلان
- اذهب إلى قسم "الإعلانات المحفوظة"
- اضغط "نشر الإعلان" بجانب الإعلان المطلوب
- راجع التفاصيل واضغط "تأكيد النشر"
- سيقوم النظام تلقائياً بالنشر إلى جميع المجموعات في المحافظة

## 🏛️ المحافظات المدعومة

يدعم النظام جميع المحافظات المصرية:
- القاهرة، الإسكندرية، الجيزة، القليوبية
- الشرقية، الدقهلية، البحيرة، كفر الشيخ
- الغربية، المنوفية، دمياط، بورسعيد
- الإسماعيلية، شمال سيناء، جنوب سيناء
- بني سويف، الفيوم، المنيا، أسيوط
- سوهاج، قنا، الأقصر، أسوان
- البحر الأحمر، الوادي الجديد، مطروح

## ⚠️ ملاحظات مهمة

1. **حقوق فيسبوك**: يُرجى الاطلاع على شروط خدمة فيسبوك قبل استخدام النظام
2. **النشر المتكرر**: تجنب النشر المتكرر السريع لتجنب حظر الحساب
3. **المجموعات الخاصة**: لا يمكن النشر في المجموعات الخاصة إلا بقبول طلب الانضمام أولاً
4. **الصور**: تأكد من أن الصور متوافقة وليست كبيرة جداً

## 🔧 المشاكل الشائعة

### لا يتم الاتصال بفيسبوك
- تأكد من أن المتصفح مفتوح
- تحقق من صحة بيانات تسجيل الدخول
- قد تحتاج لحل اختبار CAPTCHA يدوياً

### لا توجد مجموعات
- تأكد من اختيار المحافظة الصحيحة
- جرب كلمات بحث مختلفة
- بعض المجموعات قد تكون خاصة (مغلقة)

### فشل النشر
- تحقق من أن الحساب لا يزال متصلًا
- تأكد من صلاحية النشر في المجموعات
- راجع سجل الأخطاء للتفاصيل
